# BFSI Claude Code Python Training Dataset

## Business Problem
AI-Assisted Banking Transaction Monitoring, Fraud Risk Analysis, and Production Incident Resolution.

## Dataset Scale
- customers.csv: 10,000 rows
- accounts.csv: 15,000 rows
- transactions.csv: 25,000 rows
- incidents.csv: 10,000 rows
- api_logs.csv: 15,000 rows
- application_logs.csv: 20,000 rows
- test_cases.csv: 5,000 rows
- reference_data.csv: 163 rows

## Important
All records are fully synthetic. No real customer, employee, client, bank, or transaction information is included.

## Suggested Python Stack
Python 3.11+, pandas or Polars, FastAPI, Pydantic, SQLAlchemy, SQLite, Pytest, Playwright/Selenium.
